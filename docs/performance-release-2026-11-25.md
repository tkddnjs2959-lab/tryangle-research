# 매체연기 어드민 성능 개선 적용 기록

날짜: 2026-11-25 (KST). 기준 Git 원본: `68501b3`. 무료 인프라 내에서 기존 Next.js·Supabase 구조를 사용한다.

## 이번 변경

| 위치 | 변경 | 기대 효과와 한계 |
|---|---|---|
| `src/lib/admin-data.ts` 학생 목록 | 서버 페이지네이션 30건, 성별/나이 필터, 목록에 필요한 배우 이름·ID만 조회 | 전체 학생과 배우 상세 데이터를 한 번에 읽지 않는다. 기존 이름 끝의 `(YY)` 출생연도 표기를 지원하는 필터는 현재 최대 5,000건 후보를 읽으므로 증가 시 별도 정규화가 필요하다. |
| `src/lib/admin-data.ts` 상담 목록 | 상담별 녹취/분석/할 일 3회씩 하던 조회를 상담 목록 1회 + 독립 배치 3회로 변경 | 상담 N건에서 최대 `1+3N` 호출을 4회로 줄인다. 호출 시간의 실제 변화는 배포 후 측정 필요. |
| `src/lib/admin-auth.ts` | 세션과 관리자 계정 조회를 FK 조인으로 통합 | 인증 경로의 DB 왕복 1회를 줄인다. 세션 만료/비활성 계정 검증은 유지. |
| `src/app/admin/AdminTabs.tsx`, `loading.tsx`, CSS | 메뉴 선택 즉시 진행 표시, 경로 로딩 중 안내 | 서버 완료 시간과 구별되는 체감 반응을 제공한다. 실제 메뉴 완료 시간을 줄이는 작업과는 구분한다. |
| `src/app/admin/coaching/page.tsx` | 서버 필터와 페이지 링크 연동 | 목록이 커져도 첫 화면의 행 수를 일정하게 유지한다. |

추가 검토 중 발견한 나이 계산의 1년 차이와 필터 페이지 이동 시 앞부분 결과가 누락될 수 있는 문제를 수정했다. 나이는 기존 화면처럼 조회 연도에서 출생연도를 뺀 값으로 계산한다.

## 확인한 범위

- 로컬 `npm run check`의 TypeScript 타입 검사와 Next.js 프로덕션 빌드가 통과했다. CSS의 기존 `align-items: end` 자동 접두어 경고는 남아 있다.
- 브라우저 네트워크/서버 함수/SQL 지연시간은 이번 단계에서 실측하지 않았다. 개선률과 목표 달성 여부는 미확인이다.
- 운영 데이터·DB 스키마·보안 정책은 변경하지 않는다. 학생/결제 ERP 원장 이행 계획은 `erp-migration-plan.md`에 별도 정리되어 있으며 이번 코드 릴리스에 포함되지 않는다.

## 운영 확인 항목

1. 로그인과 메뉴 전환 후 학생·등록 페이지에 정상 진입하는지 확인한다.
2. 성별·나이 필터, 전체 인원, 30건 단위 이전/다음 페이지를 확인한다. 이름에 `(YY)`가 있는 기존 학생을 표본으로 비교한다.
3. 상담 상세 목록과 녹취/분석/할 일 표시가 이전과 동일한지 확인한다.
4. 로그인부터 페이지 표시, 학생 필터, 메뉴 전환의 브라우저 타이밍과 Vercel 함수 시간을 같은 조건에서 기록한다.
5. 배포 오류가 있으면 이전 READY 배포로 되돌리고 문제의 Git 커밋을 수정한다. DB 마이그레이션이 없으므로 데이터 복구는 요구되지 않는다.

## 배포 기록

Git 커밋, Vercel 배포 ID, 프로덕션 별칭, 운영 확인 결과는 실제 배포 후 기입한다. Vercel 연결 계정에서 프로젝트 목록이 비어 있어 해당 계정의 프로젝트 접근 범위와 Git 자동 배포 연결 여부는 현재 미확인이다.
